# ClassBoard 1.0

Versão pública do ClassBoard em **HTML + CSS + JavaScript** com **Supabase** para autenticação e banco de dados.

## O que já vem nesta versão
- login, cadastro e recuperação de acesso
- dashboard com visão semanal
- criação, edição e exclusão de tarefas
- checklist por tarefa
- agenda dos próximos 30 dias
- avisos do workspace
- materiais e links úteis
- workspaces por grupo, turma ou uso individual
- entrada por código
- gestão de membros e papéis
- transferência de ownership
- perfil e atualização de senha

## Como publicar
1. Rode `supabase/schema.sql` no SQL Editor do seu projeto.
2. Preencha `assets/js/config.js` com a URL do projeto e a chave pública do Supabase.
3. Suba a pasta inteira para o GitHub.
4. Ative o GitHub Pages na branch principal.

## O que ainda falta para uma versão ainda mais avançada
- anexos reais com Supabase Storage
- notificações push e email automáticas
- comentários por tarefa
- auditoria/histórico de ações
- aplicativo PWA com uso offline
- cobrança e assinatura
